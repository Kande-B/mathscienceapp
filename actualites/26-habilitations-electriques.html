Pour les filières industrielles (MELEC, Maintenance), le cours de physique-chimie prépare aux habilitations électriques. Focus sur ces normes de sécurité indispensables en entreprise. ⚡

En Bac Pro industriel, l'électricité n'est pas qu'une matière théorique. Elle est liée à un impératif absolu : l'habilitation électrique, nécessaire pour travailler en entreprise lors des stages ou après le diplôme.

👷 Que signifient les sigles B1V, BR, BC ?

Le cours de Sciences, notamment dans les chapitres sur la sécurité, aborde ces normes régies par l'INRS :

  • 🔹La première lettre : Domaine de tension (B = Basse tension, H = Haute tension).
  • 🔹Le chiffre : Type d'opération (1 = Exécutant non électricien, 2 = Chargé de travaux).
  • 🔹La dernière lettre : Nature de l'opération (V = Voisinage, R = Intervention générale, C = Consignation).

Comprendre les risques (électrisation, électrocution, court-circuit) lors des TP de sciences est la première étape pour obtenir cette précieuse habilitation professionnelle !
