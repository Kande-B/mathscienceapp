Depuis la rénovation des programmes du Baccalauréat Professionnel, l'**Algorithmique et la Programmation en langage Python** sont devenues obligatoires en cours de Mathématiques. Pas de panique ! L'objectif n'est pas de faire de vous des développeurs logiciels, mais de vous transmettre la logique algorithmique utile dans l'industrie connectée (variables, conditions if/else, boucles for/while). Mode d'emploi des attentes de l'examen.

1. Pourquoi le langage Python en Lycée Pro ?

Python est aujourd'hui le langage de programmation le plus populaire au monde dans l'industrie, l'intelligence artificielle et la recherche scientifique.

Au lycée professionnel, son enseignement permet de modéliser des problèmes mathématiques concrets : calculer automatiquement un seuil de rentabilité, simuler la trajectoire d'une pièce mécanique ou automatiser le calcul d'une série statistique.

Les 3 notions clés de Python à maîtriser pour le Bac

1. **L'Affectation de Variable :** Stocker des valeurs (ex: U = 230 ou R = 50).
2. **La Conditionnelle (Si ... Alors ... Sinon) :** if U > 230: print("Surtension") else: print("Normal").
3. **La Boucle Répétitive (Pour / Tant que) :** for i in range(10): ou while S < 1000:.

2. Comment l'algorithmique est-elle évaluée en CCF ?

En Contrôle en Cours de Formation (CCF), vous n'aurez jamais à écrire un programme complet de 100 lignes de zéro ! L'épreuve prend généralement l'une des formes suivantes :

Compléter un Script à Trous

Un script Python partiellement rédigé vous est fourni. Vous devez remplacer les pointillés par la bonne variable ou la bonne condition pour que le programme fonctionne.

Analyser l'Affichage de Sortie

On vous présente un script Python et on vous demande de prédire la valeur finale renvoyée par la fonction après l'exécution de 5 tours de boucle.

3. Attention à l'Indentation en Python !

C'est le piège syntaxique numéro 1 des débutants en Python : **l'Indentation** (le décalage vers la droite par 4 espaces).

Contrairement à d'autres langages qui utilisent des accolades {}, Python utilise le décalage pour savoir quelles lignes d'instructions appartiennent au bloc if ou for. N'oubliez jamais les **deux-points :** à la fin de la ligne d'en-tête !
