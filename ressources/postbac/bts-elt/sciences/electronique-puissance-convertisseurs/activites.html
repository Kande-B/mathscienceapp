Contextualisation Industrielle
Un hacheur Buck IGBT alimente le moteur de traction d'un véhicule utilitaire sous tension continue d'entrée $E = 600\text{ V}$ à la fréquence de découpage $f = 20\text{ kHz}$. La tension moyenne souhaitée pour le moteur est $U_{moy} = 420\text{ V}$.

Questions d'Ingénierie :

Question 1 : Calculer le rapport cyclique $\alpha$.
$\alpha = \frac{U_{moy}}{E} = \frac{420}{600} = 0,70$.
Question 2 : Calculer l'inductance $L$ minimale pour garantir une ondulation crête-à-crête $\Delta I \le 4,0\text{ A}$.
$\Delta I = \frac{\alpha(1-\alpha)E}{L f} \implies L = \frac{0,70 \times 0,30 \times 600}{4,0 \times 20000} = \frac{126}{80000} = 1,575 \times 10^{-3}\text{ H} = 1,575\text{ mH}$.
Question 3 : Si la charge absorbe un courant moyen $I_{moy} = 50\text{ A}$, vérifier si la conduction est continue.
$I_{min} = I_{moy} - \frac{\Delta I}{2} = 50 - 2,0 = 48,0\text{ A} > 0$. La conduction est strictement continue !
