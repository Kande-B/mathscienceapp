Problème CS CSMIOP (15 points) : Centrale de Laminage 3000 L

1 h 30 min
L'analyse d'huile d'une centrale de laminage ($3000 ext{ L}$) donne : $>4mu ext{m} = 4500 ext{ part/mL}$, $>6mu ext{m} = 600 ext{ part/mL}$, $>14mu ext{m} = 40 ext{ part/mL}$.
Question 2.1 : Établir le code ISO 4406 et dimensionner la durée de dépollution à $100 ext{ L/min}$. (5 pts)
C3 • CALCULER
Code ISO = **19/16/12**. Temps pour passer 7 fois le volume du bac : $t = \frac{7 \times 3000}{100} = 210\text{ minutes} = 3,5\text{ heures}$.
