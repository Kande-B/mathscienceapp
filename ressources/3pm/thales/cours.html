Le Théorème de Thalès

La condition absolue

Pour utiliser Thalès, il faut une configuration précise ("les triangles emboîtés") avec deux droites parallèles coupées par deux droites sécantes en un sommet commun.

L'égalité des rapports

Si les droites sont parallèles, alors les côtés du petit triangle sont proportionnels à ceux du grand triangle. On écrit 3 fractions égales :

$\frac{\text{Petit}}{\text{Grand}} = \frac{\text{Petit}}{\text{Grand}} = \frac{\text{Petit}}{\text{Grand}}$

Application et Réciproque

Calculer une longueur

Si on sait que les droites sont parallèles, on peut calculer une longueur manquante grâce au produit en croix.

Exemple de Rédaction :

1. On sait que (MN) // (BC).

2. D'après le th. de Thalès :

$\frac{AM}{AB} = \frac{AN}{AC} = \frac{MN}{BC}$

Je remplace : $\frac{3}{5} = \frac{4}{AC} = \frac{MN}{BC}$

3. Je calcule AC :

$AC = \frac{5 \times 4}{3} = \frac{20}{3} \approx 6,67$

Prouver que c'est parallèle

Si on connaît toutes les longueurs sur les droites sécantes, on peut prouver que les droites sont parallèles grâce à la Réciproque.

Méthode de vérification :

Je calcule séparément les rapports :

$\frac{AM}{AB} = \frac{3}{6} = \mathbf{0,5}$
$\frac{AN}{AC} = \frac{4}{8} = \mathbf{0,5}$

Les résultats sont identiques (0,5 = 0,5).

Les points sont alignés dans le même ordre, donc d'après la réciproque du th. de Thalès, les droites sont parallèles.
