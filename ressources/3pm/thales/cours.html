Séquence : Théorème de Thalès

1. La configuration de Thalès

Pour appliquer le théorème de Thalès, il faut être dans une configuration précise :

  • Deux droites sécantes (qui se croisent) en un point $A$.
  • Deux droites parallèles qui coupent ces sécantes.

Cela forme "deux triangles emboîtés" (un petit et un grand), ou une configuration "en papillon".

2. Énoncé du théorème (Calculer une longueur)

L'égalité des rapports

Si les droites $(BM)$ et $(CN)$ sont parallèles, alors les longueurs des côtés du petit triangle $ABM$ sont proportionnelles aux longueurs des côtés du grand triangle $ACN$.

$\frac{AB}{AC} = \frac{AM}{AN} = \frac{BM}{CN}$

Soit : $\frac{\text{Petit Côté}}{\text{Grand Côté}} = \frac{\text{Petit Côté}}{\text{Grand Côté}} = \frac{\text{Petite Parallèle}}{\text{Grande Parallèle}}$

Méthode de calcul (Produit en croix)

  1. Vérifier et écrire que les droites sont parallèles.
  2. Écrire l'égalité des 3 rapports de Thalès avec les lettres.
  3. Remplacer par les longueurs connues.
  4. Utiliser le produit en croix avec deux rapports pour trouver la longueur manquante.

3. La Réciproque (Montrer que c'est parallèle)

Vérifier le parallélisme

La réciproque de Thalès permet de prouver que deux droites sont parallèles.

Méthode de vérification :

On connaît les longueurs sur les droites sécantes : $AB=2$, $AC=6$ et $AM=3$, $AN=9$.

  1. Je calcule séparément : $\frac{AB}{AC} = \frac{2}{6} = \frac{1}{3}$.
  2. Je calcule séparément : $\frac{AM}{AN} = \frac{3}{9} = \frac{1}{3}$.
  3. Je compare : $\frac{AB}{AC} = \frac{AM}{AN}$ et les points sont alignés dans le même ordre.

Conclusion : D'après la réciproque du théorème de Thalès, les droites $(BM)$ et $(CN)$ sont parallèles.
