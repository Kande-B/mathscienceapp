Le Vocabulaire

Seulement pour les triangles rectangles !

Le théorème de Pythagore ne s'applique QUE si le triangle possède un angle droit (90°). Dans ce triangle, le plus grand côté porte un nom spécial :

L'Hypoténuse

  • C'est toujours le côté le plus long.
  • Il est toujours situé en face de l'angle droit.

Le Théorème

Il permet de calculer la longueur d'un côté quand on connaît les deux autres.

La Formule Magique

$\text{Hypoténuse}^2 = \text{Côté 1}^2 + \text{Côté 2}^2$

La Rédaction Parfaite (Brevet)

1. On sait que le triangle $ABC$ est rectangle en $B$.

2. D'après le théorème de Pythagore :

$AC^2 = AB^2 + BC^2$

$AC^2 = 3^2 + 4^2$

$AC^2 = 9 + 16$

$AC^2 = 25$

3. Donc $AC = \sqrt{25} = \mathbf{5 \text{ cm}}$

La Réciproque

Vérifier si un triangle est rectangle

On vous donne 3 longueurs et on vous demande : "Ce triangle a-t-il un angle droit ?".
C'est très utile dans le bâtiment pour vérifier qu'un mur est bien droit (monté "à l'équerre").

Exemple 1 : Côtés de 5, 12 et 13.

  1. Le plus long côté est 13 :
    $\rightarrow 13^2 = 169$
  2. La somme des deux autres :
    $\rightarrow 5^2 + 12^2 = 25 + 144 = 169$
  3. On compare : $169 = 169$. C'est égal !

Conclusion : D'après la réciproque du théorème de Pythagore, le triangle EST rectangle.

Exemple 2 : Côtés de 4, 5 et 7.

  1. Le plus long côté est 7 :
    $\rightarrow 7^2 = 49$
  2. La somme des deux autres :
    $\rightarrow 4^2 + 5^2 = 16 + 25 = 41$
  3. On compare : $49 \neq 41$. Ce n'est pas égal !

Conclusion : Le triangle N'EST PAS rectangle.
