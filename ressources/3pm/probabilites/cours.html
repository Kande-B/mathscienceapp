Le Hasard

Le vocabulaire des probabilités

Une expérience est aléatoire quand on ne peut pas prévoir son résultat à l'avance (ex: Lancer un dé, Tirer une carte).

  • Une Issue : C'est un résultat possible. Ex: "Faire un 4" avec un dé.
  • Un Événement : C'est une condition, souvent composée de plusieurs issues. Ex: "Faire un nombre pair" (issues: 2, 4, 6).

L'Échelle des Probabilités

0
Impossible
0,5 (ou 1/2)
1 chance sur 2
1
Certain

Règle d'or : Une probabilité est TOUJOURS comprise entre 0 et 1.

Calculer une probabilité

Quand il n'y a pas de triche (le dé n'est pas pipé), toutes les issues ont la même chance de sortir (équiprobabilité). La formule est simple :

$P = \frac{\text{Nombre de cas favorables}}{\text{Nombre total de cas possibles}}$

Exemple : Jeu de 32 cartes

Probabilité de tirer un Cœur :

  • Cartes Cœur (favorables) : 8
  • Cartes au total (possibles) : 32
  • $P = \frac{8}{32} = \frac{1}{4} = 0,25$ (soit $25\%$)
Simulateur : L'Urne Opaque

Modifiez le contenu de l'urne

P(R) = 3/6
= 50%
P(B) = 2/6
= 33%
P(V) = 1/6
= 17%

L'Événement Contraire

$P(\text{Contraire}) = 1 - P(\text{Événement})$

L'événement contraire de $A$ s'écrit $\bar{A}$ (se lit "A barre"). C'est simplement : "A ne se produit pas".

Jeu de grattage :

La probabilité de GAGNER est de $0,2$ (soit 20%).

La probabilité de PERDRE (le contraire) est :

$1 - 0,2 = 0,8$ (soit 80%)
