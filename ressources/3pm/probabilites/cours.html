Séquence : Probabilités

1. Vocabulaire des probabilités

Une expérience est aléatoire lorsqu'on ne peut pas prévoir le résultat avec certitude (ex: lancer un dé, tirer une carte).

  • Une issue : C'est un résultat possible de l'expérience (ex: "Obtenir 4" en lançant un dé).
  • Un événement : C'est une condition qui peut être réalisée par une ou plusieurs issues (ex: "Obtenir un nombre pair").
  • Événement impossible : Qui ne peut pas se produire. Sa probabilité est de 0.
  • Événement certain : Qui se produira toujours. Sa probabilité est de 1.

2. Calculer une probabilité simple

La règle de base

Quand toutes les issues ont la même chance d'arriver (on parle d'équiprobabilité), la probabilité d'un événement $A$ se calcule ainsi :

$P(A) = \frac{\text{Nombre d'issues favorables}}{\text{Nombre total d'issues possibles}}$

Exemple (Le jeu de 32 cartes) :

On tire une carte au hasard. Quelle est la probabilité de tirer un Roi ?

  • Issues favorables (les Rois) : 4 (Pique, Cœur, Carreau, Trèfle).
  • Total des issues possibles : 32 cartes.
  • Probabilité : $P(\text{Roi}) = \frac{4}{32} = \frac{1}{8} = 0,125$ (soit $12,5\%$).

Attention : Une probabilité est toujours un nombre compris entre 0 et 1. (On peut l'écrire sous forme de fraction, de décimal ou de pourcentage).

3. L'événement contraire

$P(\text{Contraire}) = 1 - P(\text{Événement})$

L'événement contraire de A, noté $\bar{A}$ (A barre), est l'événement "A ne se réalise pas".

Exemple :

La probabilité de gagner à un jeu est de $0,2$.

L'événement contraire est "perdre".

La probabilité de perdre est : $1 - 0,2 = 0,8$.
