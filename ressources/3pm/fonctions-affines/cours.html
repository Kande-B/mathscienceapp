Linéaires vs Affines

Fonction Linéaire

$f(x) = \mathbf{a}x$
  • Représente une situation de proportionnalité (ex: prix au kilo).
  • Le graphique est une droite qui passe par l'origine $(0;0)$.
  • Le nombre a est le coefficient directeur.

Fonction Affine

$f(x) = \mathbf{a}x + \mathbf{b}$
  • Souvent utilisée pour un coût fixe + coût variable (ex: forfait 10€ + 2€/min).
  • Le graphique est une droite qui ne passe pas forcément par l'origine.
  • b s'appelle l'ordonnée à l'origine (le point de départ sur l'axe vertical).

Lire le Graphique

Sur un repère, la droite d'une fonction $y = \mathbf{a}x + \mathbf{b}$ dépend de ses deux paramètres :

a Le Coefficient directeur (La pente)

Il indique de combien on "monte" ou "descend" quand on avance de 1 case vers la droite.

Si a > 0 : ça monte. Si a < 0 : ça descend.

b L'Ordonnée à l'origine (Le départ)

C'est la hauteur à laquelle la droite coupe l'axe vertical (axe des y), quand $x=0$.
