I
Chapitre 1 • Définitions Officiel EN

Conventions d'écriture et Réduction d'Expressions

Règles officielles de simplification

  • • Omission du signe $\times$ : $3 \times x = 3x \quad \text{et} \quad x \times y = xy \quad \text{et} \quad 1 \times x = x$.
  • • Carré et Cube : $x \times x = x^2 \quad \text{et} \quad x \times x \times x = x^3$.
  • • Réduction : On regroupe les termes de même nature (les $x^2$ ensemble, les $x$ ensemble, les nombres constants ensemble) : $$3x + 5x = 8x \quad \text{et} \quad 4x^2 + 2x^2 = 6x^2$$

Exemple d'application rédigé pas à pas : Périmètre d'une parcelle de chantier

Un terrain rectangulaire mesure $x$ mètres de largeur et $(2x + 3)$ mètres de longueur. Exprimer son périmètre réduit $P(x)$.

Étape 1 : Écriture de la somme des 4 côtés

$$P(x) = x + (2x + 3) + x + (2x + 3)$$

Étape 2 : Regroupement des termes en $x$ et des constantes

$$P(x) = (x + 2x + x + 2x) + (3 + 3)$$

Étape 3 : Expression réduite finale

$$P(x) = 6x + 6\text{ mètres}$$

II
Chapitre 2 • Développement Algébrique

Distributivité Simple $k(a+b)$ et Double $(a+b)(c+d)$

Distributivité Simple

$$k(a + b) = ka + kb$$ $$k(a - b) = ka - kb$$

Double Distributivité

$$(a + b)(c + d) = ac + ad + bc + bd$$

Exemple d'application rédigé pas à pas : Aire d'un atelier étendu

Développer et réduire l'expression $A(x) = (x + 3)(2x + 4)$.

Étape 1 : Application de la double distributivité (4 produits)

$$A(x) = x \times 2x + x \times 4 + 3 \times 2x + 3 \times 4$$

Étape 2 : Calcul des produits

$$A(x) = 2x^2 + 4x + 6x + 12$$

Étape 3 : Réduction des termes semblables ($4x + 6x = 10x$)

$$A(x) = 2x^2 + 10x + 12$$

III
Chapitre 3 • Résolution d'Équations

Équations du type $ax + b = c$ et $ax + b = cx + d$

Règle d'or de la balance

Une équation est une égalité de deux membres. Tout changement effectué à gauche d'une équation doit être **exactement répété à droite** pour préserver l'équilibre !

$$ax + b = cx + d \implies ax - cx = d - b \implies (a - c)x = d - b \implies x = \frac{d - b}{a - c}$$

Exemple d'application rédigé pas à pas : Équilibre de devis d'artisans

Résoudre l'équation $5x + 20 = 2x + 80$.

Étape 1 : Soustraire $2x$ des deux côtés pour regrouper les $x$ à gauche

$$5x - 2x + 20 = 80 \implies 3x + 20 = 80$$

Étape 2 : Soustraire 20 des deux côtés pour isoler $3x$

$$3x = 80 - 20 \implies 3x = 60$$

Étape 3 : Diviser par 3 pour obtenir la solution $x$

$$x = \frac{60}{3} = 20$$

La solution unique de l'équation est $x = 20$.

IV
Chapitre 4 • Produit Nul

Équations-Produits Nuls $(ax + b)(cx + d) = 0$

Propriété du Produit Nul

Un produit de facteurs est nul si et seulement si **au moins l'un des facteurs est nul** :

$$A \times B = 0 \iff A = 0 \quad \text{ou} \quad B = 0$$

Exemple d'application rédigé pas à pas : Résoudre $(2x - 8)(x + 3) = 0$

Étape 1 : Séparation des deux équations du 1er degré

$$2x - 8 = 0 \quad \text{ou} \quad x + 3 = 0$$

Étape 2 : Résolution de la 1ère équation

$$2x = 8 \implies x = \frac{8}{2} = 4$$

Étape 3 : Résolution de la 2ème équation

$$x = -3$$

Conclusion : L'équation admet deux solutions : $x = 4$ ou $x = -3$.
