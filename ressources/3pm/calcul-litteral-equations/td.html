Exercices : Calcul Littéral & Équations

1 Développement simple

Développez et réduisez les expressions suivantes :

  1. $A = 4(x + 3)$
  2. $B = 5(2x - 7)$
  3. $C = -2(x + 5)$
  4. $D = x(x - 4)$

2 Double distributivité

Développez et réduisez en utilisant la règle $(a+b)(c+d) = ac+ad+bc+bd$ :

  1. $E = (x + 2)(x + 4)$
  2. $F = (x - 3)(x + 5)$
  3. $G = (2x + 1)(x - 2)$

3 Identités remarquables

Développez les expressions suivantes à l'aide des identités remarquables :

  1. $H = (x + 3)^2$ (Indice : $(a+b)^2 = a^2+2ab+b^2$)
  2. $I = (x - 5)^2$ (Indice : $(a-b)^2 = a^2-2ab+b^2$)
  3. $J = (x - 4)(x + 4)$ (Indice : $(a-b)(a+b) = a^2-b^2$)

4 Vérifier une solution

On donne l'équation : $4x - 5 = 7$.

  1. Le nombre $x = 2$ est-il solution de cette équation ? Justifiez par un calcul.
  2. Le nombre $x = 3$ est-il solution de cette équation ? Justifiez par un calcul.

5 Résolutions simples

Résolvez les équations suivantes pour trouver la valeur de $x$ :

  1. $x + 5 = 12$
  2. $x - 8 = 4$
  3. $3x = 15$
  4. $\frac{x}{2} = 6$

6 Résolutions avec deux étapes

Résolvez ces équations un peu plus longues (isolez d'abord les $x$, puis divisez) :

  1. $2x + 1 = 9$
  2. $5x - 3 = 17$
  3. $-3x + 4 = 10$
  4. $4x = x + 15$ (Indice : mettez tous les "x" du côté gauche)

7 Problème : Le club de sport

Pour s'inscrire dans une salle de sport, il faut payer des frais de dossier de 20 €, puis 15 € par mois.

Le prix payé pour $x$ mois d'abonnement est donné par l'expression : $15x + 20$.

  1. Calculez le prix payé pour 6 mois d'abonnement (Remplacez $x$ par 6).
  2. Un client a payé 140 € au total. Écrivez une équation pour trouver combien de mois il est resté inscrit.
  3. Résolvez l'équation pour répondre à la question.

8 Problème : Équilibre des périmètres

On a un carré de côté $x$. Son périmètre est donc $4 \times x = 4x$.
On a un triangle équilatéral dont chaque côté mesure $x + 2$. Son périmètre est $3(x + 2)$.

  1. Développez l'expression du périmètre du triangle : $3(x + 2)$.
  2. On veut que le carré et le triangle aient exactement le même périmètre. Écrivez l'équation correspondante.
  3. Résolvez cette équation pour trouver la valeur de $x$.
