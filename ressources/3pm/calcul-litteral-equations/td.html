Ex 1 Simplification et Réduction d'Expressions

Calculer (REA)

Réduisez les expressions littérales suivantes :

  1. $A = 5x + 3x - 2x$
  2. $B = 7x + 4 + 2x + 9$
  3. $C = 4x^2 + 3x - 2x^2 + 5x$

Corrigé rédigé :

  1. $A = (5 + 3 - 2)x = 6x$.
  2. $B = (7x + 2x) + (4 + 9) = 9x + 13$.
  3. $C = (4x^2 - 2x^2) + (3x + 5x) = 2x^2 + 8x$.

Ex 2 Développement par Distributivité Simple

Représenter (REG)

Développez et réduisez les expressions suivantes :

  1. $D = 4(x + 5)$
  2. $E = 3(2x - 7)$
  3. $F = 5x(x + 2)$

Corrigé rédigé :

  1. $D = 4 \times x + 4 \times 5 = 4x + 20$.
  2. $E = 3 \times 2x - 3 \times 7 = 6x - 21$.
  3. $F = 5x \times x + 5x \times 2 = 5x^2 + 10x$.

Ex 3 Résolution d'Équations Simples ($ax = b$)

Calculer (REA)

Résolvez les équations suivantes :

  1. $x + 8 = 19$
  2. $5x = 35$
  3. $3x - 4 = 14$

Corrigé rédigé :

  1. $x = 19 - 8 \implies x = 11$.
  2. $x = 35 / 5 \implies x = 7$.
  3. $3x = 14 + 4 = 18 \implies x = 18 / 3 \implies x = 6$.

Ex 4 Problème Métier : Facture de l'Artisan Plombier

Modéliser (MOD)

Un artisan plombier facture un déplacement fixe de 40 € puis 35 € par heure $h$ d'intervention.

  1. Écrivez la formule du prix total $P(h)$ en fonction du nombre d'heures $h$.
  2. Si le client paie une facture de 180 €, combien d'heures l'artisan a-t-il travaillées ? Écrivez et résolvez l'équation.

Corrigé rédigé :

  1. Formule du prix : $P(h) = 35h + 40$.
  2. Équation : $35h + 40 = 180 \implies 35h = 140 \implies h = 140 / 35 = 4\text{ heures}$.

Ex 5 Équation avec Inconnue des Deux Côtés ($ax+b = cx+d$)

Calculer (REA)

Résolvez les équations à deux membres :

  1. $7x + 5 = 4x + 23$
  2. $9x - 12 = 3x + 18$

Corrigé rédigé :

  1. $7x - 4x = 23 - 5 \implies 3x = 18 \implies x = 6$.
  2. $9x - 3x = 18 + 12 \implies 6x = 30 \implies x = 5$.
