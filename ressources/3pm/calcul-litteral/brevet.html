Annales Officieuses & Sujets Brevet : 6 Sujets de Calcul Littéral

Sujet 1 • DNB PRO Métropole Bâtiment & Expression du Périmètre d'une Terrasse

20 Points

Un maçon fabrique une terrasse rectangulaire de largeur $x\text{ m}$ et de longueur $(2x + 5)\text{ m}$.

Questions :

  1. (5 points) Écrivez la somme des 4 côtés exprimant le périmètre $P(x)$.
  2. (5 points) Réduisez l'expression du périmètre sous la forme $P(x) = ax + b$.
  3. (5 points) Calculez le périmètre exact pour une largeur $x = 6\text{ m}$.
  4. (5 points) Développez l'expression de l'aire de la terrasse $A(x) = x(2x + 5)$.

Corrigé rédigé - Sujet 1 (20 Points) :

  1. $P(x) = x + (2x + 5) + x + (2x + 5)$. (5 pts)
  2. $P(x) = 6x + 10\text{ m}$. (5 pts)
  3. Pour $x = 6$ : $P(6) = 6(6) + 10 = 46\text{ m}$. (5 pts)
  4. $A(x) = 2x^2 + 5x\text{ m}^2$. (5 pts)

Sujet 2 • DNB PRO Centres Étrangers Menuiserie & Double Distributivité

20 Points

La surface d'un plateau en bois composé sur mesure est modélisée par l'expression $S(x) = (x + 4)(3x + 2)\text{ cm}^2$.

Questions :

  1. (6 points) Développez cette expression en détaillant les 4 multiplications.
  2. (7 points) Réduisez les termes semblables pour obtenir une expression sous la forme $ax^2 + bx + c$.
  3. (7 points) Calculez la surface pour $x = 5\text{ cm}$.

Corrigé rédigé - Sujet 2 (20 Points) :

  1. $S(x) = x \times 3x + x \times 2 + 4 \times 3x + 4 \times 2$. (6 pts)
  2. $S(x) = 3x^2 + 2x + 12x + 8 = 3x^2 + 14x + 8$. (7 pts)
  3. Pour $x = 5$ : $S(5) = 3(25) + 14(5) + 8 = 75 + 70 + 8 = 153\text{ cm}^2$. (7 pts)

Sujet 3 • DNB PRO Polynésie Modélisation du Coût d'Expédition de Matériel

20 Points

Un service logistique facture une expédition d'outillages selon la formule $C(x) = 3,50x + 25$, où $x$ est la masse en kg.

Questions :

  1. (6 points) Calculez le coût pour une masse $x = 10\text{ kg}$.
  2. (7 points) Calculez le coût pour une masse $x = 40\text{ kg}$.
  3. (7 points) Que représente la valeur constante 25 dans la formule du coût ?

Corrigé rédigé - Sujet 3 (20 Points) :

  1. $C(10) = 3,50(10) + 25 = 35 + 25 = 60\text{ €}$. (6 pts)
  2. $C(40) = 3,50(40) + 25 = 140 + 25 = 165\text{ €}$. (7 pts)
  3. La valeur 25 représente le forfait fixe d'envoi / de traitement. (7 pts)

Sujet 4 • DNB PRO Métropole Remplacement Électricité & Calcul Littéral

20 Points

La puissance électrique consommée par une baie de serveurs est donnée par $P(I) = 220I + 50$, où $I$ est l'intensité en ampères.

Questions :

  1. (7 points) Calculez la puissance $P(I)$ pour $I = 5\text{ A}$.
  2. (7 points) Calculez la puissance $P(I)$ pour $I = 16\text{ A}$.
  3. (6 points) Si l'intensité double, la puissance est-elle exactement doublée ? Justifiez par un calcul.

Corrigé rédigé - Sujet 4 (20 Points) :

  1. $P(5) = 220(5) + 50 = 1\,100 + 50 = 1\,150\text{ W}$. (7 pts)
  2. $P(16) = 220(16) + 50 = 3\,520 + 50 = 3\,570\text{ W}$. (7 pts)
  3. Pour $I = 5\text{ A}$, $P = 1\,150\text{ W}$. Si l'intensité double ($I = 10\text{ A}$), $P(10) = 220(10) + 50 = 2\,250\text{ W}$. Or $2 \times 1\,150 = 2\,300\text{ W}$. La puissance n'est donc pas exactement doublée à cause du terme fixe de 50 W. (6 pts)

Sujet 5 • DNB PRO Antilles-Guyane Maçonnerie & Volume d'un Coffrage Béton

20 Points

Un coffrage rectangulaire de fondation a pour largeur $x\text{ m}$, longueur $(x + 3)\text{ m}$ et une hauteur fixe de $0,5\text{ m}$.

Questions :

  1. (7 points) Écrivez l'expression du volume de béton $V(x) = 0,5 \times x \times (x + 3)$.
  2. (7 points) Développez cette expression sous la forme $V(x) = ax^2 + bx$.
  3. (6 points) Calculez le volume de béton nécessaire pour $x = 4\text{ m}$.

Corrigé rédigé - Sujet 5 (20 Points) :

  1. $V(x) = 0,5x(x + 3)$. (7 pts)
  2. $V(x) = 0,5x^2 + 1,5x\text{ m}^3$. (7 pts)
  3. Pour $x = 4$ : $V(4) = 0,5(16) + 1,5(4) = 8 + 6 = 14\text{ m}^3\text{ de béton}$. (6 pts)

Sujet 6 • DNB PRO Nouvelle-Calédonie Factorisation & Identités Remarquables Usuelles

20 Points

On considère l'expression littérale $E(x) = x^2 - 64$.

Questions :

  1. (7 points) Factorisez l'expression $E(x)$ à l'aide de l'identité remarquable $a^2 - b^2$.
  2. (7 points) Calculez la valeur de $E(10)$.
  3. (6 points) Calculez la valeur de $E(8)$. Que remarque-t-on ?

Corrigé rédigé - Sujet 6 (20 Points) :

  1. $E(x) = x^2 - 8^2 = (x - 8)(x + 8)$. (7 pts)
  2. $E(10) = (10 - 8)(10 + 8) = 2 \times 18 = 36$. (7 pts)
  3. $E(8) = (8 - 8)(8 + 8) = 0 \times 16 = 0$. La valeur $x = 8$ annule l'expression $E(x)$. (6 pts)
