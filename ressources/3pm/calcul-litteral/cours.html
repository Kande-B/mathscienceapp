Règles d'écriture

Le langage de l'algèbre

En mathématiques, pour alléger l'écriture avec des lettres, on peut "cacher" le signe multiplier (×) dans certains cas :

  • Devant une lettre : 3 × x = 3x
  • Devant une parenthèse : 2 × (x + 1) = 2(x + 1)
  • Entre deux lettres : a × b = ab
  • Et x multiplié par x : x × x = x²

Développement et Factorisation

Développer (Distribuer)

C'est transformer un produit en une somme ou soustraction. On distribue le facteur extérieur à l'intérieur des parenthèses.

k(a + b) = ka + kb

Exemple : 3(x + 4)

➜ 3 × x + 3 × 4

➜ 3x + 12

Factoriser (Regrouper)

C'est le chemin inverse ! On transforme une somme en produit en trouvant un "facteur commun".

ka + kb = k(a + b)

Exemple : 5x + 15

➜ 5×x + 5×3

➜ 5(x + 3)

Les Identités Remarquables

Ce sont des formules de développement "raccourcies" qu'il faut connaître par cœur pour gagner du temps.

Le carré d'une somme

(a + b)² = a² + 2ab + b²
Ex: (x + 3)²
= x² + 2(x)(3) + 3²
= x² + 6x + 9

Le carré d'une différence

(a - b)² = a² - 2ab + b²
Ex: (x - 5)²
= x² - 2(x)(5) + 5²
= x² - 10x + 25

Différence de deux carrés

(a + b)(a - b) = a² - b²
Ex: (x + 4)(x - 4)
= x² - 4²
= x² - 16
