3ème Prépa-Métiers • TD

Exercices : Repérage (Axe, Plan, Espace)

1 Repérage sur une droite (Abscisse)

Tracez une droite graduée d'origine $O$, d'unité 1 cm. Placez les points suivants :

  • $A(-3)$
  • $B(4)$
  • $C(2,5)$
  • $D(-1,5)$

2 Lecture de coordonnées

Dans un repère, on donne les coordonnées suivantes. Indiquez quelle est l'abscisse et quelle est l'ordonnée pour chaque point :

  • $E(4 ; -2)$ : L'abscisse est ... et l'ordonnée est ...
  • $F(-1 ; 5)$ : L'abscisse est ... et l'ordonnée est ...
  • $G(0 ; 3)$ : L'abscisse est ... et l'ordonnée est ...

3 Placement de points dans le plan

Sur une feuille à carreaux, tracez un repère orthonormé (1 carreau = 1 unité) et placez les points suivants :

$P(2 ; 3)$
$Q(-3 ; 1)$
$R(-2 ; -4)$
$S(4 ; -2)$

Quelle figure géométrique obtenez-vous en reliant $P-Q-R-S$ ?

4 Vrai ou Faux ?

  • L'axe horizontal est l'axe des ordonnées. (Vrai / Faux)
  • Le point $M(0 ; 5)$ est situé sur l'axe des ordonnées. (Vrai / Faux)
  • Le point d'intersection des deux axes s'appelle l'origine et a pour coordonnées $(0 ; 0)$. (Vrai / Faux)
  • Pour le point $N(-3 ; 2)$, le nombre -3 est l'abscisse. (Vrai / Faux)

5 Problème : Relevé de coordonnées (Topographie)

Un géomètre doit placer 3 piquets pour délimiter un terrain triangulaire. Le piquet A est à l'origine $(0 ; 0)$. Le piquet B est situé à 4 mètres à l'Est (droite) et 0 mètre au Nord. Le piquet C est situé à 0 mètre à l'Est et 3 mètres au Nord.

1. Donnez les coordonnées des points $A$, $B$ et $C$.

2. Placez ces points dans un repère (1 carreau = 1 mètre).

3. Quelle est la nature du triangle $ABC$ ?

6 Repérage dans l'espace

Dans un repère de l'espace à trois dimensions, un point est défini par 3 coordonnées : $(x ; y ; z)$ représentant (abscisse ; ordonnée ; altitude). Indiquez l'altitude des points suivants :

  • Un drone $D$ est situé aux coordonnées $(15 ; 20 ; 45)$. Son altitude est de ... mètres.
  • Un sous-marin $S$ est situé aux coordonnées $(120 ; 300 ; -50)$. Son altitude est de ... mètres.
  • Une voiture $V$ garée au sol aux coordonnées $(10 ; 5 ; 0)$. Son altitude est de ... mètres.

7 Problème de la bataille navale

Dans un jeu vidéo inspiré de la bataille navale, la carte est un repère. Votre bateau est en $B(3 ; -2)$ et le trésor est en $T(-1 ; 4)$.

1. Placez ces points dans un repère.

2. De combien de cases vers la gauche (horizontalement) et vers le haut (verticalement) devez-vous avancer pour aller de $B$ à $T$ ?

8 Déplacement d'un bras robotique (Industrie)

Un bras robotique industriel doit souder des pièces sur une carte mère. L'origine $(0;0)$ est le coin inférieur gauche de la carte. Les coordonnées sont en millimètres.

  • Le point de soudure 1 est à $S1(20 ; 50)$.
  • Le point de soudure 2 est à $S2(60 ; 50)$.
  • Le point de soudure 3 est à $S3(60 ; 10)$.

1. Représentez la carte (1 carreau = 10 mm) et placez les 3 points de soudure.

2. Le robot se déplace en ligne droite de S1 à S2, puis de S2 à S3. Décrivez ses mouvements (exemple : "il avance de X mm vers la droite").
