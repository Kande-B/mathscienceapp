Séquence 3 : Repérage (Axe, Plan, Espace)

1. Repérage sur une droite (Axe)

L'abscisse

Sur une droite graduée, chaque point est repéré par un seul nombre relatif appelé son abscisse.

On note $A(3)$ pour dire que l'abscisse du point $A$ est $3$.

2. Repérage dans un plan

Le repère orthonormé

Un plan est muni d'un repère orthogonal lorsqu'il est composé de deux droites graduées perpendiculaires qui se croisent en un point $O$ (l'origine).

  • L'axe horizontal est l'axe des abscisses (noté $x$).
  • L'axe vertical est l'axe des ordonnées (noté $y$).

Lire et placer des coordonnées

Chaque point du plan est repéré par un couple de nombres $(x ; y)$ appelés ses coordonnées :

Point $A(x ; y)$ $\rightarrow$ $A(\text{abscisse} ; \text{ordonnée})$

Attention à l'ordre ! L'abscisse (horizontale) se lit toujours en premier, suivie de l'ordonnée (verticale).

3. Repérage dans l'espace (Initiation)

Les trois dimensions

Pour se repérer dans l'espace (en 3D), il faut trois axes et donc trois coordonnées :

  • $x$ : l'abscisse (largeur)
  • $y$ : l'ordonnée (profondeur)
  • $z$ : l'altitude (ou cote) (hauteur)
