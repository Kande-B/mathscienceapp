Sur une droite (1D)

L'abscisse

Sur une droite graduée, chaque point est repéré par un seul nombre appelé son abscisse. On l'écrit entre parenthèses à côté du point.

A(3) signifie que l'abscisse de A est 3.
2

Dans un plan (2D)

Coordonnées (x; y)

Un plan utilise deux axes perpendiculaires pour se repérer :

  • L'axe horizontal : L'axe des abscisses (les $x$).
  • L'axe vertical : L'axe des ordonnées (les $y$).

Point A ( Abscisse ; Ordonnée )

Dans l'espace (3D)

Les Trois Dimensions

Pour se repérer dans un volume (une pièce, l'espace 3D), on ajoute un 3ème axe vertical pour la hauteur : l'axe des cotes (ou altitudes).

  • x L'abscisse (largeur)
  • y L'ordonnée (profondeur)
  • z La cote / altitude (hauteur)
Point M ( x ; y ; z )

Exemple concret

Un drone en vol est repéré par un GPS en 3D :

Il a parcouru 10m vers l'Est (x=10), 5m vers le Nord (y=5), et vole à une hauteur de 20m (z=20).

Ses coordonnées : D(10; 5; 20)
