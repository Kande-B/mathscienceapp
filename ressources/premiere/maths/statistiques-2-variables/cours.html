Statistiques à Deux Variables

Nuage de points, point moyen $G(\bar{x} \,;\, \bar{y})$, droite d'ajustement linéaire $y = ax + b$ et prédictions.

I Série Statistique à Deux Variables et Nuage de Points

Définition : Nuage de Points

Une série statistique à deux variables quantitatives mesure deux grandeurs $X$ et $Y$ sur une même population. Elle est représentée par une suite de couples de valeurs $(x_1 \,;\, y_1), (x_2 \,;\, y_2), \dots, (x_n \,;\, y_n)$.
L'ensemble des points $M_i(x_i \,;\, y_i)$ placés dans un repère orthogonal constitue le nuage de points.

Exemple d'illustration : Ancienneté et Salaire

Pour 3 salariés, on relève l'ancienneté $X$ (en années) et le salaire $Y$ (en k€) : $(1 ; 20)$, $(3 ; 24)$, $(5 ; 28)$. Les 3 points du nuage sont $M_1(1 ; 20)$, $M_2(3 ; 24)$ et $M_3(5 ; 28)$.

II Le Point Moyen $G(\bar{x} \,;\, \bar{y})$

Définition & Propriété du Point Moyen $G$

Le point moyen d'un nuage de points, noté $\mathbf{G(\bar{x} \,;\, \bar{y})}$, est le point dont les coordonnées sont les moyennes arithmétiques des deux variables :

$$\bar{x} = \frac{x_1 + x_2 + \dots + x_n}{n} \quad \text{et} \quad \bar{y} = \frac{y_1 + y_2 + \dots + y_n}{n}$$

Exemple d'illustration : Calcul des Coordonnées de $G$

Pour la série précédente $(1 ; 20)$, $(3 ; 24)$, $(5 ; 28)$ ($n = 3$) :

  • $\bar{x} = \frac{1 + 3 + 5}{3} = \frac{9}{3} = \mathbf{3}$
  • $\bar{y} = \frac{20 + 24 + 28}{3} = \frac{72}{3} = \mathbf{24}$

Le point moyen est $G(3 \,;\, 24)$.

III Ajustement Affine (Droite de Tendance $y = ax + b$)

Propriété Fondamentale de la Droite d'Ajustement

Lorsque le nuage de points présente une forme allongée, on peut ajuster ce nuage par une droite d'équation $\mathbf{y = a x + b}$.

$$\text{La droite d'ajustement passe obligatoirement par le point moyen } G(\bar{x} \,;\, \bar{y}) \implies \mathbf{\bar{y} = a \bar{x} + b}$$

Exemple d'illustration : Équation de la Droite $y = 2x + 18$

Pour la pente $a = 2$ et le point moyen $G(3 ; 24)$ :

$b = \bar{y} - a \bar{x} = 24 - (2 \times 3) = 24 - 6 = \mathbf{18}$.

L'équation de la droite d'ajustement est $y = 2 x + 18$.

IV Exemple Rédigé d'Application Professionnelle

Application : Prédiction de Consommation de Carburant

La consommation $Y$ d'un poids lourd en fonction de la vitesse $X$ est modélisée par $y = 0{,}4 x + 5$.

1. Prédiction pour une vitesse $x = 90\ \text{km/h}$ :
$y = 0{,}4(90) + 5 = 36 + 5 = \mathbf{41\ \text{L/100km}}$.

2. Vitesse pour une consommation maximale de $33\ \text{L/100km}$ :
$33 = 0{,}4 x + 5 \implies 0{,}4 x = 28 \implies x = \frac{28}{0{,}4} = \mathbf{70\ \text{km/h}}$.
