Dérivation et Étude de Variations

Nombre dérivé, interprétation géométrique de la tangente, dérivées usuelles et méthode d'optimisation.

I Nombre Dérivé et Interprétation Géométrique

Définition : Nombre Dérivé $f'(x_0)$

Soit $f$ une fonction numérique et $\mathcal{C}_f$ sa courbe représentative.
Le nombre dérivé de $f$ en un point d'abscisse $x_0$, noté $\mathbf{f'(x_0)}$, est le coefficient directeur (la pente) de la droite tangente $(T)$ à la courbe au point $A\big(x_0 \,;\, f(x_0)\big)$.

Exemple d'illustration : Équation de la Tangente en $x_0 = 2$

Pour $f(x) = x^2$, au point d'abscisse $x_0 = 2$ : $f(2) = 4$ et $f'(2) = 2(2) = 4$.

L'équation de la droite tangente $(T)$ s'écrit :

$$y = f'(2)(x - 2) + f(2) = 4(x - 2) + 4 = 4x - 8 + 4 = \mathbf{4x - 4}$$

II Tableau des Dérivées Usuelles & Opérations

Fonction $f(x)$ Fonction Dérivée $f'(x)$ Exemple d'application
$f(x) = k$ (constante) $f'(x) = 0$ $f(x) = 7 \Rightarrow f'(x) = 0$
$f(x) = a x + b$ $f'(x) = a$ $f(x) = -4x + 3 \Rightarrow f'(x) = -4$
$f(x) = x^2$ $f'(x) = 2x$ $f(x) = 5x^2 \Rightarrow f'(x) = 5(2x) = 10x$
$f(x) = x^3$ $f'(x) = 3x^2$ $f(x) = x^3 - 2 \Rightarrow f'(x) = 3x^2$
$f(x) = \frac{1}{x}$ $f'(x) = -\frac{1}{x^2}$ $f(x) = \frac{4}{x} \Rightarrow f'(x) = -\frac{4}{x^2}$

Exemple d'illustration : Dérivation Terme à Terme d'un Polynôme

Pour dériver $f(x) = 3 x^2 - 12 x + 5$ :

$f'(x) = 3(2x) - 12(1) + 0 = \mathbf{6x - 12}$.

III Signe de la Dérivée et Sens de Variation

Théorème Fondamental de Variation

Le signe de la fonction dérivée $f'(x)$ gouverne directement les variations de la fonction $f(x)$ :

f'(x) > 0

f est Stricte. Croissante ↗

f'(x) = 0

Sommet / Extremum ⟷

f'(x) < 0

f est Stricte. Décroissante ↘

Exemple d'illustration : Étude du Signe de $f'(x) = 6x - 12$

$6x - 12 = 0 \iff 6x = 12 \iff x = 2$.

  • Pour $x < 2$, $f'(x) < 0 \implies f$ est décroissante ↘.
  • Pour $x > 2$, $f'(x) > 0 \implies f$ est croissante ↗.

$f$ admet un minimum en $x = 2$.

IV Méthode d'Étude d'une Fonction et Optimisation

Application Rédigée : Optimisation d'un Bénéfice $B(x) = -x^2 + 6x - 5$

1. Dérivée : $B'(x) = -2x + 6$.
2. Racine : $-2x + 6 = 0 \iff x = 3$.
3. Le bénéfice maximal vaut $B(3) = -(3)^2 + 6(3) - 5 = \mathbf{4\ \text{k€}}$.
