TP TICE : Tableau de Fréquences et Simulation de Tirages Conditionnels

Formules Tableur clés : `=SOMME(B2:B3)` pour calculer les marges, `=B2/$D2` pour la probabilité conditionnelle $P_A(B)$, et `=NB.SI()` pour compter les occurrences dans une simulation de 1 000 tirages.

1

Protocole d'Expérimentation sous Tableur (Excel / LibreOffice Calc)

Étape 1 : Saisir la grille d'effectifs

Dans les cellules B2:C3, saisissez les effectifs usine ($B2 = 40$, $C2 = 560$, $B3 = 20$, $C3 = 380$).
Dans la cellule $D2$, tapez la formule de somme : =SOMME(B2:C2).

Étape 2 : Calculer automatiquement les probabilités conditionnelles

Dans la cellule $E2$, tapez la formule donnant la probabilité de défaut sachant l'usine A $P_A(D)$ :
=B2/D2.
Le tableur affiche automatiquement 0,06666... (soit 6,7 %).

Étape 3 : Simuler 1 000 tirages aléatoires

Utilisez la formule =ALEA.ENTRE.BORNES(1;100) pour simuler le tirage aléatoire et observer la convergence vers $P(D) = 0{,}06$.
