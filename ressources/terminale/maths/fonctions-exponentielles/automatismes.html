Comment simplifier les expressions $e^a \times e^b$ et $\frac{e^a}{e^b}$ ?

Cliquer pour voir la réponse
Règles de Calcul

$$e^a \times e^b = e^{a+b}$$

$$\frac{e^a}{e^b} = e^{a-b} \quad \text{et} \quad \frac{1}{e^a} = e^{-a}$$

Dérivée de $e^{kx}$

Quelle est la fonction dérivée de $f(x) = e^{kx}$ ($k \in \mathbb{R}^*$) ?

Cliquer pour voir la réponse
Formule de Dérivation

$$\mathbf{(e^{kx})' = k e^{kx}}$$

Exemple : $(e^{-0{,}5x})' = -0{,}5 e^{-0{,}5x}$.

Cliquez pour revenir
Sens de Variation

Comment varie la fonction $f(x) = e^{kx}$ selon le signe de $k$ ?

Cliquer pour voir la réponse
Croissance / Décroissance

• Si $k > 0 \implies f$ est **strictement croissante** $\nearrow$.

• Si $k < 0 \implies f$ est **strictement décroissante** $\searrow$.

Cliquez pour revenir
Signe de l'Exponentielle

Quel est le signe de $e^x$ pour n'importe quel nombre réel $x \in \mathbb{R}$ ?

Cliquer pour voir la réponse
Strictement Positive

$$\mathbf{e^x > 0 \quad \text{pour tout } x \in \mathbb{R}}$$

Une fonction exponentielle n'est **jamais négative ni nulle**.

Cliquez pour revenir
Résolution d'Équation

Comment résoudre l'équation $e^x = b$ pour $b > 0$ ?

Cliquer pour voir la réponse
Logarithme Népérien

$$\mathbf{x = \ln(b)}$$

Si $b \le 0$, l'équation n'a aucune solution.
