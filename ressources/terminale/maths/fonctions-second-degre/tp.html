Équations / Fonctions
Application « Équations » Solveur
  • • Ouvrir l'application Équations $\rightarrow$ Ajouter une équation.
  • • Choisir le modèle quadratique $a x^2 + b x + c = 0$.
  • • Saisir les valeurs de $a$, $b$ et $c$.
  • • Sélectionner Résoudre l'équation : la calculatrice affiche $\Delta$, $x_1$ et $x_2$.
Application « Fonctions » Graphique
  • • Saisir $f(x) = a x^2 + b x + c$ dans l'onglet Fonctions.
  • • Passer sur l'onglet Graphique.
  • • Appuyer sur OK $\rightarrow$ Calculer :
    - Extremum : positionne le curseur directement sur le sommet $S$.
    - Zéros : trouve les intersections avec l'axe $(Ox)$.

Aérodynamisme & Ingénierie des Transports

Étude de Cas : Profil Aérodynamique d'un Déflecteur de Toit

35 min

Mise en situation :

Le profil supérieur d'un carénage aérodynamique de cabine de camion de 2 mètres de long est modélisé par la fonction $y = f(x)$ définie sur $[0 ; 2]$ par :

$$f(x) = -0{,}6x^2 + 1{,}2x + 3{,}2 \quad (x \text{ et } y \text{ en mètres})$$

1. Saisir la fonction $f(x)$ dans l'application Fonctions de votre NumWorks.

2. Utiliser le menu Calculer > Extremum pour relever les coordonnées exactes du point culminant du déflecteur.

3. Résoudre $f(x) = 3{,}5$ à l'aide de l'application Équations pour déterminer sur quel intervalle le carénage dépasse 3,50 m de hauteur.

  • 1. Saisie NumWorks : $f(x) = -0.6 x^2 + 1.2 x + 3.2$.
  • 2. Extremum : Sommet en $x_S = \mathbf{1{,}00\text{ m}}$ avec $y_S = \mathbf{3{,}80\text{ m}}$.
  • 3. Équation $f(x) = 3{,}5$ : $$-0{,}6x^2 + 1{,}2x + 3{,}2 = 3{,}5 \iff -0{,}6x^2 + 1{,}2x - 0{,}3 = 0$$ $\Delta = (1{,}2)^2 - 4(-0{,}6)(-0{,}3) = 1{,}44 - 0{,}72 = \mathbf{0{,}72} > 0$. $$x_1 = \frac{-1{,}2 + \sqrt{0{,}72}}{-1{,}2} \approx \mathbf{0{,}29\text{ m}} \quad \text{et} \quad x_2 = \frac{-1{,}2 - \sqrt{0{,}72}}{-1{,}2} \approx \mathbf{1{,}71\text{ m}}$$ La hauteur dépasse 3,50 m pour $x \in [\mathbf{0{,}29\text{ m}} ; \mathbf{1{,}71\text{ m}}]$.
