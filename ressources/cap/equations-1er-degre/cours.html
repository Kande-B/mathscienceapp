Partie 1 • Définitions

Qu'est-ce qu'une Équation ?

Définition Officielle

Une **équation** est une égalité comportant un nombre inconnu désigné par une lettre (généralement $x$).
**Résoudre une équation**, c'est trouver la valeur de $x$ qui rend l'égalité vraie.

2
Partie 2 • Méthode Générale

Résolution en 2 Étapes pour $a x + b = c$

Méthode en 2 Étapes

Pour résoudre $a x + b = c$ :
1. **Étape 1** : Soustraire (ou ajouter) $b$ de chaque côté : $a x = c - b$.
2. **Étape 2** : Diviser par $a$ : $x = \frac{c - b}{a}$.
